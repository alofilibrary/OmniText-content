# Provenance records

Create one Markdown file per pack id. It must state:

1. Exact work, translator/editor, language, canon/scope, and edition date.
2. License grant and a stable URL or included license text proving commercial
   redistribution is permitted.
3. Required attribution, modification, share-alike, or notice obligations.
4. Exact upstream repository URL, full commit SHA, and source path.
5. Source-file SHA-256 values and the final generated pack SHA-256.
6. Conversion command/tool version and validation results.
7. Reviewer, review date, and explicit `approved` or `rejected` decision.

Never infer a text license from the license of surrounding code, a GitHub topic,
or a friendly-looking README.
